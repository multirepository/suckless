# suckless universal environment

## Patches
1. actualfullscreen - https://dwm.suckless.org/patches/actualfullscreen/
2. pertag - https://dwm.suckless.org/patches/pertag/
3. systray - https://dwm.suckless.org/patches/systray/

## Build dependencies
`build-essential libx11-dev libxft-dev libxinerama-dev make xinit xserver-xorg`

## Configuration dependencies
`alacritty`

## Build
```sh
git clone https://github.com/multirepository/suckless
```
```sh
cd suckless && ./build.sh
```
